## Android
APK release otomatis via GitHub Actions → `Releases`. Install APK `Ganify-vX.Y.Z.apk` (signed, `versionCode` auto-increment, `versionName` = `X.Y.Z`).

- `system` search `fix(patch) → 1.0.1`, `feat(minor) → 1.1.0`, `breaking(major) → 2.0.0`
- Release: `Actions → Release Ganify → Run workflow → bump patch/minor/major`
